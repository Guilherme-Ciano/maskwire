# Configuration reference

Generated by `go run ./internal/tools/configdoc` from the config structs and their defaults; edit
`internal/tools/configdoc/descriptions.go`, not this file.

maskwire reads a YAML file (`--config` or `MASKWIRE_CONFIG`) overlaid by environment variables named
`MASKWIRE_<SECTION>__<KEY>`, for example `MASKWIRE_SERVER__ADDR`. Lists such as
`routes[]` and `tenants[]` are set in the file. Tenant settings can be reloaded with SIGHUP;
everything else needs a restart.

| Key | Type | Default | Description |
|---|---|---|---|
| `server.addr` | string | `:8090` | proxy listener |
| `server.admin_addr` | string | `127.0.0.1:9090` | metrics, health and optional pprof listener; keep it off public interfaces |
| `server.read_header_timeout` | duration | `5s` | time allowed to read request headers |
| `server.read_timeout` | duration | `30s` | time allowed to read the whole request |
| `server.idle_timeout` | duration | `2m0s` | keep-alive idle timeout for client connections |
| `server.upstream_timeout` | duration | `1m0s` | time to upstream response headers before a 504 |
| `server.stream_idle_timeout` | duration | `1m0s` | longest wait for upstream bytes in a stream before it is cut; 0 disables |
| `server.shutdown_drain_delay` | duration | `5s` | time `/readyz` reports not ready before the listener closes |
| `server.shutdown_timeout` | duration | `20s` | time in-flight requests get to finish on shutdown |
| `server.max_body_bytes` | integer | `4194304` | request body limit; larger bodies get 413 |
| `server.tenant_header` | string | `X-Maskwire-Key` | header carrying the tenant API key, stripped before forwarding |
| `server.session_header` | string | `X-Maskwire-Session` | conversation id for `token_scope: session`, stripped before forwarding |
| `server.default_tenant` | string |  | tenant used when the key header is missing; leave empty in production |
| `server.pprof` | bool |  | serve `/debug/pprof` on the admin listener |
| `keys.master_key` | string |  | hex master key, at least 32 bytes; prefer `MASKWIRE_KEYS__MASTER_KEY` or `master_key_file` |
| `keys.master_key_file` | string |  | file holding the hex master key; must not be readable by group or others |
| `keys.version` | integer | `1` | key version (1-65535); changing it rotates every tenant's tokens |
| `audit.enabled` | bool | `true` | write the HMAC-chained audit log |
| `audit.dir` | string | `audit` | audit directory; one JSONL file per tenant and UTC day |
| `audit.on_full` | string | `block` | `block` waits for the writer when its buffer is full; `drop` counts and drops |
| `audit.buffer` | integer | `4096` | audit events buffered in memory |
| `audit.anchor_file` | string |  | append chain heads here every 5 s for `audit verify --anchors`; keep it off the audit volume |
| `audit.retention_days` | integer |  | delete day files older than this many days through a sealed retention ledger, so verification still passes; 0 keeps everything |
| `detect.regions` | list of string | `BR,PT,ES,DE,FR,IT` | regions used to parse and validate phone numbers |
| `detect.phone_budget` | integer | `64` | libphonenumber validations per request; beyond it, phone-shaped runs are masked unvalidated |
| `detect.disable_phone` | bool |  | turn phone detection off |
| `detect.keep_reserved_email` | bool |  | also mask addresses at reserved domains such as `example.com`, which are skipped by default |
| `detect.names` | bool |  | detect person names (preview): first-name gazetteer plus surnames, honorifics and labels such as `nome:`; see docs/evaluation.md |
| `detect.max_entities` | integer | `4096` | distinct entities per request before it is rejected with 422 |
| `log.level` | string | `info` | `debug`, `info`, `warn` or `error` |
| `log.format` | string | `json` | `json` or `text` |
| `tracing.endpoint` | string |  | OTLP/HTTP traces endpoint such as `http://jaeger:4318`; empty disables tracing |
| `tracing.sample_ratio` | number | `1` | fraction of new traces sampled (0-1); incoming sampled parents are always followed |
| `vault.backend` | string |  | store for cross-turn restore: `memory` (single instance) or `redis`; empty disables it |
| `vault.redis_addr` | string |  | Redis address for the `redis` backend |
| `vault.redis_password_file` | string |  | file holding the Redis password |
| `vault.ttl` | duration | `24h0m0s` | how long a conversation's tokens stay restorable after its last request |
| `vault.max_entries` | integer | `1000000` | entry limit of the `memory` backend |
| `routes[].name` | string |  | route name used in metrics and audit records |
| `routes[].path` | string |  | path served by maskwire |
| `routes[].upstream` | string |  | upstream URL; with a path it is used as is, without one the incoming path is appended |
| `routes[].codec` | string |  | `openai`, `openai-responses`, `openai-embeddings`, `anthropic` or `passthrough` (GET only, no body) |
| `routes[].synthesize_stream` | bool |  | turn a JSON reply into SSE when the client asked for a stream, for caches that only store JSON |
| `tenants[].id` | string |  | tenant id: letters, digits, `-`, `_`, `.`; at most 64 characters |
| `tenants[].key_sha256` | string |  | sha256 of the tenant API key; `maskwire gen-key` creates both |
| `tenants[].mode` | string |  | `enforce`, or `observe` to count detections and forward raw values |
| `tenants[].default` | string |  | action for types without a rule: `mask`, `redact`, `block` or `allow` |
| `tenants[].by_type.<TYPE>.action` | string |  | action for one entity type |
| `tenants[].by_type.<TYPE>.min_score` | number |  | minimum detection score (0-1) for the action to apply |
| `tenants[].token_length` | integer |  | token suffix length, 5-10 |
| `tenants[].prompt_hint` | bool |  | add a short instruction to copy placeholders verbatim when a request carries tokens |
| `tenants[].response_scan` | string |  | `observe` counts personal data the model generated itself; `off` |
| `tenants[].foreign_token` | string |  | tokens not issued for the request become `[email]` (`generic`) or stay as they are (`keep`) |
| `tenants[].tool_restore` | list of string |  | entity types restored inside tool-call arguments: `all`, `none` or a list of types |
| `tenants[].token_scope` | string |  | `tenant` (deterministic), `session` (per `X-Maskwire-Session`) or `request` (fresh per request) |
| `tenants[].cross_turn_restore` | bool |  | restore tokens issued in earlier requests of the same `X-Maskwire-Session`; needs `token_scope: session` and a vault |
| `tenants[].rate_limit.rps` | number |  | requests per second; 0 disables the limit |
| `tenants[].rate_limit.burst` | integer |  | bucket size; defaults to the rate rounded up |
